Privacy policy

Effective 2026-11-17 · Publisher: Sachin Shankar

Short version: Ignis runs on your computer and keeps your data there. It has no accounts, no analytics, no telemetry and no crash reporting. The publisher receives nothing about you or how you use it.

What stays on your machine

Your models, your chats, your Rebound bots, their memory and routines, the folders and files you open in Code, its checkpoints, and your settings. A chat with a local model is answered by the model on your computer. Your messages are not sent to a server to get a reply.

When Ignis connects to the internet

Ignis goes online only for the tasks below, and only when you use the feature that needs them.

  • Marketplace and model downloads (Hugging Face). Ignis requests model listings, files and model cards, and the model file you choose to download.
  • Packages. ignis search and ignis install read the package index on the Bouncer site (bouncer-ai.pages.dev), or the address you give them.
  • Installing (GitHub). The install script asks the GitHub API for the newest release of shankar-sachin/get-ignis and downloads it. There is no updater yet, so the app itself does not check for updates.

These services receive each request the way a browser would send it, so their own privacy policies apply to what they log: Hugging Face and GitHub. Ignis adds no identifiers of its own.

This website is hosted on Cloudflare Pages, which is governed by its own privacy policy. The pages of this site load no analytics or tracking scripts. The docs page loads two scripts (marked and DOMPurify) from jsDelivr, and the pages load the Geist fonts from Google Fonts.

The local API

The local API runs while the Ignis service runs. It listens on 127.0.0.1 only, so only programs on your computer can reach it. Requests to it are answered by the model on your computer.

Deleting your data

Uninstalling Ignis and deleting its data folder removes everything it stored. The folder is ~/Library/Application Support/Bouncer Ignis. The model library is shared with Bouncer, so deleting a model removes it for both apps.

Changes

If this policy changes, the new version is published in the get-ignis repository and noted in its changelog. The effective date at the top shows the latest version.

Contact

Questions about privacy go to GitHub issues. The longer version is in the docs.
