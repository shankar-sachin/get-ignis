# Examples

Starting points you can copy:

- [rebound-bots.md](rebound-bots.md): three bot personalities and a routine for [Rebound](../docs/rebound.md), with the fields to fill in the bot builder.
- [local-api.py](local-api.py): a small Python client for the [local API](../docs/local-api.md). It uses only the standard library. It lists your models, asks one question and streams the reply.
- [local-api.sh](local-api.sh): the same checks with curl.

The files in this folder may be copied and adapted freely for your own projects.
