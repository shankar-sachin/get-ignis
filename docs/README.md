# Bouncer Ignis documentation

These pages are also on the website at https://bouncer-ai.pages.dev/ignis/docs.

Bouncer Ignis runs open models on your own Mac, so chats and files stay local. It is the lean edition of Bouncer, written in Rust. These pages cover how to install it, how to use each part, and where to get help.

## Start

- [Getting started](getting-started.md): install, your first model and your first chat.
- [Install](install.md): the install command, manual downloads, checksums and uninstalling.
- [Updates](updates.md): how to update by hand. There is no updater yet.
- [System requirements](system-requirements.md): supported systems and memory.

## Use Ignis

- [Chat](chat.md): talk with a model you have loaded.
- [Code](code.md): work on a folder with a model, with changes you review before they apply.
- [Rebound](rebound.md): make bots, give them a memory, a folder or calendar to read and a voice, and run them on a schedule.
- [Models](models.md): the library, the Marketplace and packages.
- [Terminal commands](cli.md): `ignis`, the background service, and `bi`, the terminal chat.
- [Settings](settings.md): appearance, the service and your hardware.
