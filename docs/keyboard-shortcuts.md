# Keyboard shortcuts

These shortcuts work in the Ignis app. The main modifier is <kbd>⌘</kbd> (Command). For the terminal chat, see [Terminal commands](cli.md#keys-in-the-chat).

## Everywhere

| Action | Keys |
| --- | --- |
| Open the command palette | <kbd>⌘</kbd> <kbd>K</kbd> |
| Close the command palette | <kbd>Esc</kbd> |
| Open Settings | <kbd>⌘</kbd> <kbd>,</kbd> |
| Quit | <kbd>⌘</kbd> <kbd>Q</kbd> |

## Switching screens

| Screen | Keys |
| --- | --- |
| Chat | <kbd>⌘</kbd> <kbd>1</kbd> |
| Code | <kbd>⌘</kbd> <kbd>2</kbd> |
| Rebound | <kbd>⌘</kbd> <kbd>4</kbd> |
| Marketplace | <kbd>⌘</kbd> <kbd>6</kbd> |

The **Chat** and **Code** buttons in the title bar switch between those two screens too.

## Chat

| Action | Keys |
| --- | --- |
| New chat | <kbd>⌘</kbd> <kbd>N</kbd> |
| Send message | <kbd>Enter</kbd> |
| New line in the composer | <kbd>Shift</kbd> <kbd>Enter</kbd> |
| Stop a reply | <kbd>Esc</kbd> |
| Cancel renaming a chat | <kbd>Esc</kbd> |

## Code

| Action | Keys |
| --- | --- |
| Send message | <kbd>Enter</kbd> |
| New line in the composer | <kbd>Shift</kbd> <kbd>Enter</kbd> |
| Cycle the mode (Plan, Manual, Accept edits, Autopilot) | <kbd>Shift</kbd> <kbd>Tab</kbd> |
| Stop Code while it works | <kbd>Esc</kbd> |
| Show or hide the terminal panel | <kbd>Ctrl</kbd> <kbd>`</kbd> |
| Pick the highlighted file in the `@` menu | <kbd>Enter</kbd> |
| Close the `@` menu | <kbd>Esc</kbd> |

While the terminal has focus, <kbd>Shift</kbd> <kbd>Tab</kbd> goes to the shell.

## Text fields

Text fields in Ignis take the usual Mac editing keys.

| Action | Keys |
| --- | --- |
| Move by character | <kbd>←</kbd> <kbd>→</kbd> |
| Move by word | <kbd>⌥</kbd> <kbd>←</kbd> <kbd>→</kbd> |
| Start or end of the line | <kbd>⌘</kbd> <kbd>←</kbd> <kbd>→</kbd>, or <kbd>Home</kbd> <kbd>End</kbd> |
| Select by character | <kbd>Shift</kbd> <kbd>←</kbd> <kbd>→</kbd> |
| Select all | <kbd>⌘</kbd> <kbd>A</kbd> |
| Cut, copy, paste | <kbd>⌘</kbd> <kbd>X</kbd>, <kbd>⌘</kbd> <kbd>C</kbd>, <kbd>⌘</kbd> <kbd>V</kbd> |
| Delete the word before the caret | <kbd>⌥</kbd> <kbd>Backspace</kbd> |
